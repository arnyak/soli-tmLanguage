# Soli TextMate Grammars

TextMate grammars for the [Soli](https://github.com/solisoft/soli_lang) programming language,
suitable for [GitHub Linguist](https://github.com/github-linguist/linguist), VS Code, Sublime Text,
Nova and any other TextMate-compatible highlighter.

| Grammar | Scope | Files |
| ------- | ----- | ----- |
| [`grammars/soli.tmLanguage.json`](grammars/soli.tmLanguage.json) | `source.soli` | `*.sl` |
| [`grammars/html.soli.tmLanguage.json`](grammars/html.soli.tmLanguage.json) | `text.html.soli` | `*.slv` (HTML views with `<% %>` / `<%= %>` tags) |
